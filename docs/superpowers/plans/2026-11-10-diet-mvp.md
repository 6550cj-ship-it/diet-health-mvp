# 饮食健康 MVP 实现计划

目标为用户任务文件 `PROMPT.md`，在本目录交付可直接运行的标准库项目。

## 结构和约束

- `diet_mvp/__init__.py` 只负责把源码包纳入路径，公式唯一入口在 `src/diet_mvp/nutrition/bmi_energy.py`。
- `nutrition/interfaces.py` 固定枚举和不可变结果类型，deepseek 只替换公式文件函数体。
- `foods/catalog.py` 验证和加载 34 项离线示例，`off_client.py` 用 urllib 做可选补充。
- `planner/recommender.py` 使用餐次候选和有界搜索，自写算法，不依赖外部应用。
- `cli.py` 提供中文及 JSON 输出，README、INTERFACE、RUN_LOG 记录使用和验收。
- Python 3.11+、零第三方运行依赖，不创建虚拟环境、不初始化 Git、不使用付费服务。

## 重点输入和验收

- NaN、无穷、布尔值和非整数年龄应以 ValueError 拒绝。
- BMI 使用原始值分级，显示值舍入，测试各临界点和临界点下方。
- non_binary 分别使用男女 PA 求值，再取结果均值，阈值相等不警告。
- 稀缺食物目录和极端热量仍应给出可解释结果，非正热量不冒充可食用方案。
- OFF 缺字段、无效数值、超时和错误 JSON 必须回退，默认 CLI 不联网。
